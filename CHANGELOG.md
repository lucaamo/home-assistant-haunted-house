# Changelog

## 0.1.0-beta.1 — 2026-10-22

- Generic package with persistent global controls and one-time safe initialization.
- UI blueprint for any number of named rooms, selected motion/occupancy sensors, lights/groups and speakers.
- Alexa Media Player, Sonos announcements, generic audio URLs, and optional per-room last-sound memory.
- Gentle color/dimmer effects with individual snapshots, nested light groups, and cleanup on normal completion.
- Silent preview by default, native dashboard, examples, installation and audio documentation.
- Home Assistant 2026.10.2 minimum; beta compatibility and recovery limits documented.
